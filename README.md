# SmartFlow AI (v0.2)

Интерактивный симулятор управления четырёхсторонним светофорным перекрёстком: микроскопическая модель движения с поворотами и разворотами, конфликтные зоны, фазы по манёврам, два алгоритма управления, метрики и воспроизводимые эксперименты. Работает целиком в браузере, без сервера и ключей.

> Название проекта историческое. Адаптивный контроллер здесь **основан на правилах** (актуированное управление по очередям и времени ожидания), машинного обучения в проекте нет.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 54 теста корректности (node:test через tsx)
npm run build      # статическая сборка в dist/ (base: './', можно класть на GitHub Pages)
npm run preview
```

Требуется Node.js 18+.

## Модель

**Геометрия.** 4 въезда по 2 полосы. Стоп-линия отнесена на 6 м от края пересекаемой дороги (радиус бордюра), поэтому радиус правого поворота 7,75 м, левого 14,75 м. Разворот построен как полуокружность радиусом 3,5 м: это половина расстояния между левой полосой въезда и правой полосой выезда. Для реального легкового автомобиля это тесно, модель здесь упрощена.

**Маршруты.** Путь = въездная полоса + соединитель + полоса выезда. Соединитель — кубическая кривая Безье, повторяющая дугу окружности (k = 0,5523·R), у «прямо» — отрезок. Путь разбит на точки через 0,25 м с направлением и кривизной. Скорость ограничена боковым ускорением 2,5 м/с²; заранее рассчитан профиль торможения перед кривой (≤ 2 м/с²). Ограничение проверяется по всему кузову.

**Разметка полос** (настройка):
- *только налево* — левая полоса: налево и разворот; правая: прямо и направо;
- *налево + прямо* — левая: налево, разворот, прямо; правая: прямо и направо.

Перестроений нет: полоса выбирается при появлении машины.

**Генерация.** На каждое прибытие делается ровно три обращения к ГПСЧ своего въезда: интервал, манёвр и полоса. Поэтому спрос не зависит от контроллера и настроек и одинаков в парах эксперимента. Доли манёвров задаются для каждого въезда и нормируются. Разворот разрешается отдельно для каждого въезда; если он запрещён, его доля не учитывается.

**Конфликтные зоны.** Для каждой пары маршрутов перебираются положения обоих автомобилей на соединителях (шаг 0,5 м) и проверяется пересечение прямоугольников 4,5 × 1,8 м с запасом 0,3 м. Зона пары — диапазон положений, при которых кузова могут пересечься. Типы зон: пересечение, слияние в одну полосу выезда, расхождение из одной полосы.

**Допуск на въезд.** Решение принимается на расстоянии v²/(2·2,5) + v·1 с + 2 м до стоп-линии. Допуск даётся, если выполнены все условия:
1. сигнал маршрута разрешающий;
2. въезжает первой в своей полосе;
3. никто из конфликтующих не держит общие зоны;
4. для уступающего манёвра у каждого защищённого конфликтующего потока время прибытия к зоне больше, чем время освобождения зоны + 1,5 с.

Получив допуск, машина держит все зоны своего пути и освобождает каждую, проехав её. Если на жёлтом машина может остановиться, допуск снимается. Первая стоящая уступающая машина может завершить поворот в первые 0,5 с жёлтого.

**Почему нет взаимных блокировок.** Машина с допуском никогда не ждёт зону. Её лидер тоже имеет допуск или уже на полосе выезда, а у полос выезда нет затора ниже по потоку. Все зоны берутся разом, поэтому ситуации «держу одну и жду другую» не бывает.

**Фазы.**

| Режим | Фазы | Налево / разворот |
|---|---|---|
| с уступкой | С–Ю, В–З | разрешены на зелёный, уступают встречному прямому |
| отдельная фаза | левые С–Ю → прямые С–Ю → левые В–З → прямые В–З | защищены в своей фазе (встречные левые не пересекаются) |

План строится автоматически: маршрут защищён, если не конфликтует с уже защищёнными в фазе, иначе уступает. `validatePlan` проверяет, что в одной фазе нет двух защищённых конфликтующих маршрутов.

**Контроллеры.** Фиксированный: зелёный С–Ю, В–З и левых фаз. Адаптивный (правила, не ML): минимальный и максимальный зелёный, разрыв потока в зоне детектора 40 м, давление = очередь + ожидание / вес; фазы без спроса пропускаются.

**Метрики.** Ожидание — время со скоростью < 0,5 м/с, включая ожидание въезда в модель. Задержка — время в пути минус время свободного проезда по профилю скорости маршрута. По каждому манёвру считаются: обслужено, среднее ожидание, текущая и максимальная очередь.

**Проверки безопасности на каждом шаге**, независимо от логики допуска:
- две машины конфликтующих маршрутов одновременно в общей зоне;
- геометрическое пересечение кузовов (теорема о разделяющей оси);
- пересечение стоп-линии на красный;
- аварийные ограничения позиции;
- минимальный зазор.

## Тесты

`npm test` — 54 теста (≈ 50 с):
- **геометрия:** 20 путей непрерывны и гладкие, конечное направление верное, скорость на кривых ограничена;
- **конфликты:** таблица симметрична; найдены пересечения, слияния и расхождения; нет ложных конфликтов (встречные прямые, правые, левые);
- **фазы:** в обоих режимах, с разворотами и без, нет одновременно защищённых конфликтующих потоков, каждый маршрут обслуживается, запрещённый разворот не попадает в план;
- **безопасность:** 2 режима левого × 2 разметки × 2 контроллера × 2 seed × 20 мин со смешанным потоком — ноль нарушений по всем проверкам, зазор > 1 м;
- **красный:** машины всех манёвров стоят до стоп-линии; на каждом шаге зелёные защищённые маршруты не конфликтуют;
- **повороты:** все манёвры завершаются в нужном направлении, время внутри перекрёстка < 30 с, боковое ускорение ≤ 1,2 от допустимого;
- **блокировки:** высокая нагрузка 1 ч — каждые 10 мин обслуживается каждый манёвр;
- **воспроизводимость:** одинаковый seed даёт одинаковый результат, спрос одинаков для контроллеров, доли манёвров соответствуют заданным, сохранение машин.

## Известные ограничения и наблюдения

- Нет перестроений, пешеходов и разных типов транспорта.
- Удержание зоны с момента допуска (за 40–55 м до линии на скорости) консервативно: это снижает пропускную способность разрешённого левого.
- При сильном встречном потоке (≥ 700–800 авт/ч на въезд) разрешённый левый почти не обслуживается, очередь растёт неограниченно. Это ожидаемое поведение; нужна отдельная фаза.
- Общая полоса «налево + прямо» при отдельной левой фазе резко снижает пропускную способность: прямые и левые блокируют друг друга. Это реальный эффект, интерфейс о нём предупреждает.
- В режиме 4 фаз адаптивный контроллер в части сценариев уступает фиксированному. Правила давления рассчитаны на 2 фазы; результат не подгонялся.
- Около 5% защищённых машин за прогон ждут уступающую машину, которая уже заняла зону, в основном при смене фаз. Это безопасно, но приоритет не абсолютный (см. «priorityBlocked» в метриках).
- Метрики считаются с t = 0, без разогрева. Эксперимент выполняется в основном потоке.
