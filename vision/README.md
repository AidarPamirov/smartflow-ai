# Компьютерное зрение SmartFlow AI

Модули анализа видео с дорожной камеры: детекция машин, сопровождение, скорость, пересечение сплошной линии, плотность и очередь, ремень безопасности. Работают отдельно от сайта, на Python и OpenCV, на обычном CPU, без GPU. Браузер видео не обрабатывает: страница `#cv` только показывает результаты проверки.

**Чего здесь нет.** Реальные камеры Бишкека проект не подключает, записей с улиц Бишкека не использует, лица и номера не распознаёт и не хранит.

Проверка двух видов:
- **реальное размеченное видео UA-DETRAC** — публичный научный набор, камеры над дорогами Пекина и Тяньцзиня. На нём измерены детекция и счёт машин;
- **синтетическая сцена** с известной «правдой». На ней измерены скорость и пересечение сплошной: у реального набора нет калибровки камеры и разметки скорости.

⟨REAL_SHORT⟩

## Синтетическая сцена: результаты коротко

12 прогонов: 6 условий съёмки × 2 seed по 90 с, 25 кадров/с, OpenCV 5.0. Посчитано 21.10.2026.

- **Скорость** по калибровке: средняя ошибка 2–3 км/ч, 95 % ошибок не больше 4–8 км/ч. Все настоящие превышения найдены (22 из 22). Ложных событий 4 за все прогоны: событие получили машины, которые на самом деле ехали не быстрее 62 км/ч.
- **Детекция** надёжна только для машин, видимых отдельно: полнота 80–91 %. Перекрытые машины (почти половина случаев в этой сцене, особенно в очереди) сливаются в одно пятно: полнота 13–20 %. Это главное ограничение классического детектора.
- **Сплошная линия:** в свободном потоке найдено 10 пересечений из 14, ложных событий 0. В плотном потоке найдено 3 из 27: машина, которая перестраивается, перекрывается соседями, и модуль честно отвечает «недостаточно данных» (20 случаев), а не придумывает нарушение. Одно ложное событие было при сильном шуме.
- **Отказы:** без калибровки скорость, линия и метрические показатели отсутствуют («нет данных»), детекция и треки работают. Во время пропажи кадров модули сообщают «нет кадра», а после восстановления продолжают работу.
- **Ремень:** модели нет, проверять нечего. Всегда «невозможно определить».
- **Тесты:** 37 на Python и проверки данных на TypeScript, все проходят.

## Модули

```
vision/smartflow_cv/
  calibration.py                 пиксели ↔ метры на плоскости дороги (гомография по ≥ 4 опорным точкам)
  vehicle_detection.py           детекция: вычитание фона по цвету (OpenCV); YOLOX-tiny через OpenCV DNN; адаптер ultralytics
  vehicle_tracking.py            сопровождение: IoU + венгерский алгоритм, анонимные номера треков
  speed_estimation.py            скорость: перемещение в метрах за 1 с (МНК) + проверка ограничения
  lane_crossing_detection.py     пересечение сплошной: траектория против отрезка линии в метрах, гистерезис
  traffic_density_estimation.py  плотность, очередь от стоп-линии, поток через линию подсчёта
  seatbelt_assessment.py         ремень: проверка качества кадра + интерфейс специализированной модели (модели нет)
  pipeline.py                    конвейер: модули включаются независимо, у каждого статус
  synthetic.py                   синтетическая сцена с известной «правдой» и запись тестового видео
  evaluate.py                    проверка точности на синтетике по условиям съёмки → public/data/cv/cv-results.json
  detrac_eval.py                 проверка на реальном видео UA-DETRAC → public/data/cv/cv-real-results.json
  run.py                         обработка записанного видео из командной строки
```

| Модуль | Как устроен | Проверен на |
|---|---|---|
| `vehicle_detection` | классический: разница кадра с моделью фона по цвету, морфология, связные области. Фон обновляется только там, где машин нет, поэтому стоящая в очереди машина не «растворяется» | синтетической сцене; на реальном видео почти не работает (см. ниже) |
| `vehicle_detection`, нейросеть | YOLOX-tiny (Megvii, Apache-2.0), предобучен на COCO, без дообучения; запуск через OpenCV DNN на CPU, без PyTorch. Веса (20 МБ) скачиваются отдельно и проверяются по SHA-256 | реальном видео UA-DETRAC; на синтетике не проверялся |
| `vehicle_tracking` | сопоставление рамок соседних кадров по IoU венгерским алгоритмом, предсказание по скорости рамки; трек подтверждается после 3 попаданий | синтетической сцене |
| `speed_estimation` | точка касания дороги (низ рамки) → метры по калибровке; скорость — наклон прямой x(t), y(t) за последнюю секунду. **Не по размеру машины в кадре.** Без калибровки — «нет калибровки», при короткой истории — «недостаточно данных», при низкой уверенности превышение не фиксируется | синтетической сцене |
| `lane_crossing_detection` | линия — отрезок в метрах на дороге, а не линия на экране. Событие — только если точка трека ушла за линию не меньше чем на 0,6 м, пересечение внутри отрезка и без скачков рамки. Неглубокий заезд, край линии, потерянный трек, скачок рамки (слияние двух машин) — «недостаточно данных». Одно событие на трек | синтетической сцене |
| `traffic_density_estimation` | число машин по полосам, плотность (авт/км/полосу), очередь — цепочка стоящих машин от стоп-линии, поток — пересечения линии подсчёта | синтетической сцене |
| `seatbelt_assessment` | проверка качества фрагмента салона (разрешение, резкость, блики) и подключаемая модель с порогом уверенности; результаты «предположительно пристёгнут / не пристёгнут / невозможно определить» | **не проверен: модели нет**. Без модели всегда «невозможно определить» |

Адаптер `YoloDetector` (пакет `ultralytics`) подключается флагом `--detector yolo`, он не входит в зависимости и не проверялся. Проверенный нейросетевой путь — `YoloxOnnxDetector`: без файла весов он сообщает «недоступен», а не падает.

**Статусы модулей:** `ok`, `off` (выключен), `no_calibration`, `no_frame` (камера не дала кадр), `unavailable` (нет модели), `insufficient_data`. Если модуль не может дать число, он возвращает статус, а не ноль.

**Приватность.** На выходе только агрегаты и анонимные события: номер трека внутри одного прогона, время, координаты на дороге, скорость, уверенность. Кадры, вырезки, лица и номера не сохраняются. Все события — предварительные, не юридическое заключение.

⟨REAL_SECTION⟩

## Синтетическая сцена

Прямая дорога из трёх полос по 3,5 м. Неподвижная камера на высоте 12 м, наклон 24°, кадр 960×540, 25 кадров/с; в кадре участок примерно 9–55 м от камеры. Машины — параллелепипеды 4,5 × 1,8 × 1,45 м разных цветов. Они едут по модели IDM, стоят на красный у стоп-линии в 50 м (красный 30 с, зелёный 25 с) и перестраиваются, в том числе через сплошную на отрезке 18–38 м. Каждый восьмой водитель едет 70–80 км/ч, остальные около 52 км/ч.

Для каждого кадра известны точные рамки машин с учётом заслонения, их положение на дороге, скорость и все пересечения разметки. Калибровка камеры для синтетики известна точно; на реальной камере её нужно получить по разметке известного размера (`Calibration.from_points`).

Синтетика проще реальности: нет теней, дождя, ночи, бликов, грузовиков, дрожания камеры и перестроений, при которых машины задевают друг друга.

## Точность по условиям съёмки

Машина должна быть найдена, если она в 10–56 м от камеры и видна хотя бы на 60 %. Совпадение рамки с «правдой» — IoU ≥ 0,5. Среднее по двум seed; в скобках — ложные события.

## Как запустить

```bash
pip install -r vision/requirements.txt        # opencv-python-headless, numpy, scipy
cd vision
python -m unittest discover -s tests -t .      # тесты модулей, около 3 минут
python -m smartflow_cv.evaluate --out ../public/data/cv          # проверка на синтетике, около 30 минут на CPU
python -m smartflow_cv.detrac_eval --out ../public/data/cv/cv-real-results.json   # реальное видео: скачивает ~200 МБ кадров и веса YOLOX в ~/.cache

# тестовое видео: записать синтетическое и обработать его как запись с камеры
python -m smartflow_cv.synthetic --out demo --seconds 20
python -m smartflow_cv.run --video demo/synthetic.avi --calibration demo/calibration.json --config demo/camera.json --out events.json
```

Своё видео: нужна калибровка этой камеры (JSON с гомографией, см. `calibration.py`) и `camera.json` с линией и зоной в метрах на дороге. Без калибровки работают только детекция и треки. Если размер кадра не совпадает с калибровкой, обработка останавливается с ошибкой: неверные метры хуже, чем никаких.
